# Free Resume Builder — Create a Professional CV Online

A free **online resume builder**: fill a simple form and watch a clean, professional CV update live beside it — then print or save as PDF. No sign-up, no watermark, no fees.

**Live demo:** open `index.html` in any browser (or enable GitHub Pages on this repo).

## Features

- Live preview while you type (name, title, contact, summary)
- Skills rendered as clean tags
- Experience & education lists, one entry per line
- Print-optimized layout — Save as PDF from the print dialog
- Fully client-side; nothing is uploaded anywhere

## Tech

Plain HTML + CSS + JavaScript (zero dependencies).
